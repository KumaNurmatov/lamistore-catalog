# Lamistore — загрузка каталога в Тильду

Пайплайн: товарная матрица → карточки → CSV для импорта в Магазин Тильды.

## Запуск

```
python3 scripts/parse_matrix.py                      # matrix.xlsx -> data/products.json
python3 scripts/scrape_locfloor.py                   # текстуры LOC FLOOR Tempo
python3 scripts/scrape_eparket.py L1258-04431 ...    # PERGO / AQUAFLOOR / ALSAFLOOR
python3 scripts/contact_sheet.py                     # лист кандидатов, выбрать выкладку
python3 scripts/apply_picks.py                       # выбранные -> textures/<АРТИКУЛ>.jpg
python3 scripts/render_cards.py                      # карточки -> cards/*.png
python3 scripts/build_handoff.py АРТ1 АРТ2 ...       # страница для ручной заливки
python3 scripts/build_site.py                        # витрина-демо
python3 scripts/export_tilda.py --base-url URL       # -> data/tilda_import.csv
```

## Источники текстур

| Бренд | Источник | Позиций в матрице |
|---|---|---|
| LOC FLOOR | locfloor.ru (официальный) | 7 |
| PERGO | eparket.com | 10 |
| AQUAFLOOR | eparket.com | 70 |
| ALSA FLOORING | eparket.com | 28 |
| LAMI FLOOR | источник не найден | 16 |

У `scrape_eparket.py` артикул можно сузить брендом: `511@alsafloor-herringbone` —
иначе короткий номер поймает посторонний товар (на `511` без подсказки
находилась потолочная розетка).

`render_cards.py` можно запустить для отдельных позиций: `python3 scripts/render_cards.py LFT643`.

## Статус

| Этап | Готово |
|---|---|
| Матрица распарсена | 131 / 131 |
| Текстуры собраны | 18 |
| Карточки отрисованы | 17 |
| Отобрано для ручного теста | 10 (`handoff/`) |
| CSV собирается | да, все 131 строки |

Не хватает текстур для **114 позиций**. Источник найден для всех, кроме
LAMI FLOOR (16 позиций) — этот бренд в доступных магазинах не встречается,
фото нужно запрашивать у заказчика.

## Что нужно уточнить

- **Шаблон карточки.** Геометрия снята с макета на глаз, вся она в константах
  `scripts/card_template.py`. Когда будут точные значения из Figma (размер холста,
  кегли, цвет рамки лейбла, радиусы) — правим константы и перерисовываем всё одним прогоном.
- **Шрифт.** Сейчас Helvetica Neue. В макете, похоже, Inter — нужно подтвердить.
- **Углы карточки — строго прямые, фон непрозрачный.** Скругление оставляет
  прозрачные уголки, которые на тёмном фоне выглядят чёрными: `RADIUS = 0`
  и `--default-background-color=ffffffff`.
- **Пропорции карточки.** Отрисовка 1200×1500 (4:5) по макету, а блок каталога
  на сайте настроен на 3:4. Либо меняем блок, либо холст.
- **Формат CSV.** Колонки по спецификации импорта Магазина Тильды, но вживую не проверялись —
  первый импорт делать на 2–3 строках, а не на всех 131.
- **Колонка True/False** в матрице (17 из 131) — пока уходит в JSON как `flag`, в CSV не попадает.
- **Названия декоров AQUAFLOOR.** В матрице их нет, на карточке вместо декора
  печатается артикул. Магазины тоже дают только «Space Parquet Light» без названия декора.
- **Расхождение по ALSA 706.** В матрице декор называется Molly, на eparket — Canavese Blond.
- **Маркетинговый текст** в поле `Text` сейчас только из характеристик матрицы;
  описания с сайтов производителей кладутся в `description` в products.json.

## Структура

```
data/matrix.xlsx           исходная товарная матрица
data/products.json         нормализованные 131 позиция
data/tilda_import.csv      файл импорта
textures/<АРТИКУЛ>.<ext>   исходные текстуры декоров
cards/<sku>.png            готовые карточки
cards/_preview.png         превью-лист для согласования
handoff/index.html         10 позиций с полями для ручного заведения в Тильде
handoff/cards/             картинки этих 10 позиций
textures/_candidates/      все скачанные кадры + _sheet.png для выбора
data/texture_picks.json    какой кадр выбран для каждого артикула
scripts/card_template.py   геометрия и стили карточки
```

## Картинки

Тильда тянет фото по URL, поэтому `cards/` надо выложить в публичный репозиторий
и передать его raw-адрес в `--base-url`.
